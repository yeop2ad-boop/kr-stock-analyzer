# 국내(한국) 콘텐츠 상업적 재이용 라이선싱 리서치

조사일: 2026-08-21. 목적: 광고가 붙는 상업 서비스(정적 사이트, GitHub Pages + Cloudflare Worker 배포)에서 한국 공공기관·언론사 콘텐츠를 매일 자동 수집해 재게시할 때의 법적 리스크 확인.

---

## 1. 국내 신기술 소스 (NTIS · KIAT · STEPI)

기존 해외판 "신기술" 섹션(`scripts/scan-techinsight.js`)은 MIT Tech Review/McKinsey/IEEE Spectrum의 표준 RSS와 OECD "AI Wonk" 목록 페이지를 파싱해, 원문은 저장하지 않고 Claude로 재요약 + AI 삽화를 생성하는 방식이다. 국내 3개 기관을 같은 방식으로 대체할 수 있는지 확인했다.

### NTIS (국가과학기술지식정보서비스)
- Open API 8종 제공(`https://www.ntis.go.kr/rndopen/api/mng/apiMain.do`): 국가R&D 과제/성과/보고서 검색, **"이슈로보는R&D"**(최신 과학기술 이슈·동향, 신기술 섹션과 가장 유사) 등.
- 저작권정책(`https://www.ntis.go.kr/ThCopyrightPolicy.do`): 공공누리(KOGL) 유형 표시가 없고, "이익을 얻거나 이에 상응하는 혜택을 누리고자 하는 경우에는 NTIS와 사전에 별도의 협의를 하거나 허락을 득하여야 한다"고 명시. 출처표시는 의무.
- **결론**: Open API는 있으나 상업적 재이용은 사전 협의·허락이 전제 조건이다. 공공누리 자유이용 대상이 아니므로, 별도 협의 없이 광고 붙은 앱에 매일 자동 게재하는 것은 계약 위반 소지가 있다.

### KIAT (한국산업기술진흥원)
- 신기술 뉴스성 RSS/오픈API(일일 기사 스트림 형태)는 확인되지 않음 — 정책연구 보고서·사업공고 위주 사이트로, MIT Tech Review류의 데일리 아티클 소스와 구조가 다르다.
- 공공누리 전용 저작권 고시 페이지는 발견되지 않았고, 일반 이용약관(`kiat.or.kr`)에는 "회원은 서비스를 이용해 얻은 정보를 가공·판매하는 등 상업적으로 이용할 수 없다"는 조항이 있음.
- **결론**: 상업적 재이용 근거 없음. 일일 신기술 피드 소스로도 구조적으로 부적합.

### STEPI (과학기술정책연구원)
- 저작권 정책(`https://stepi.re.kr/site/nwpko/05/10502000000002021012009.jsp`): 저작재산권을 전부 보유하거나 권리자 동의를 받은 저작물에 한해 **건별로** 공공누리 제1~4유형 중 하나를 부착. 즉 모든 콘텐츠가 같은 유형이 아니라 게시물마다 다르며, 공공누리 미부착 자료는 열람만 가능(복제·배포 금지).
- 신기술 섹션처럼 매일 갱신되는 짧은 뉴스형 RSS/API는 없음(정기간행물·정책보고서 위주).
- **결론**: 상업적 이용 가능 여부는 게시물 단위로 확인해야 하며, 자동화된 일괄 수집·재게시 파이프라인에는 부적합. 제2/4유형(상업적 이용 금지)이 섞여 있어 필터링 없이 돌리면 위반 위험.

**종합**: 세 기관 모두 (a) 해외판과 같은 "매일 갱신되는 짧은 뉴스형 RSS" 자체가 없고, (b) 상업적 재이용이 기본 허용이 아니라 예외적으로만 허용되거나 사전 협의가 필요하다. 지금 방식 그대로 국내판을 만들 수 없다.

## 2. 한국/미국 언론사 뉴스 상업적 이용

### 미국 (Yahoo Finance)
- 현재 앱이 쓰는 엔드포인트는 Yahoo의 **비공식(문서화되지 않은) 내부 API**이며, Yahoo의 공식 Developer API 이용약관(`https://legal.yahoo.com/us/en/yahoo/terms/product-atos/apitnc/index.html`, Fantasy Sports API 약관 등)은 애초에 등록된 API 키를 통한 이용과 출처표시(Attribution Policy)를 전제로 한다. 비공식 엔드포인트 사용은 이 약관의 보호/허락 범위 밖에 있는 무단 접근에 가깝다.
- 헤드라인+링크만 표시(원문 전재 없음)하는 것은 저작권 텍스트 침해 소지는 낮추지만, Yahoo 서비스 이용약관 위반(비공식 접근) 문제는 별개로 남는다. 즉 "이미 문서에 unofficial/may break로 표시"한 것은 리스크의 절반만 짚은 것이고, 나머지 절반은 "합법적 라이선스 근거가 없는 상태로 상업 서비스에 쓰고 있다"는 점이다.

### 한국
- **한국언론진흥재단(KPF) + 한국디지털뉴스협회 "디지털 뉴스콘텐츠 이용규칙"**(2017.1.1 제정, `https://www.kpf.or.kr/front/board/boardContentsView.do?board_id=291&contents_id=855b0c963b5c4a42ba6b26d06c7186d4`): 업무적·상업적 목적 웹사이트가 언론사 뉴스콘텐츠를 언론사 허락 없이 복제·게시·공중송신하는 행위를 엄격히 금지. 개별 기사로 바로 연결되는 **딥링크(직접링크)** 방식으로 기사를 모아 상업적 이익을 취하는 것도 이 규칙이 문제 삼는 사례로 명시. 상업적 이용을 원하면 해당 언론사 또는 재단과 **이용계약 체결**이 원칙.
  - 참고: 한국 법원 판례상 단순 하이퍼링크 자체는 저작권 침해가 아니라는 입장이 다수이나, 이 업계 자율규칙은 "영리 목적의 기사 수집·재배열"을 별도 계약이 필요한 행위로 규정하고 있어, 계약 없이 진행 시 업계 관행·부정경쟁방지법 소지의 리스크가 남는다.
- **빅카인즈(BigKinds, KPF 운영)**: 모든 기사는 저작권법 보호 대상이며 전재·복제·배포 금지. 분석 결과(키워드·통계)는 출처(한국언론진흥재단 빅카인즈)를 밝히면 논문·도서 등 비영리 목적에 한해 별도 허락 없이 이용 가능하나, **기사 본문 인용(제목 포함 여부는 불명확하나 안전하게 보면 포함)은 저작권 구매가 필요**(뉴스저작권팀 02-2001-7792). 광고 붙은 상업 앱의 일일 헤드라인 노출용으로 그대로 쓰기엔 부적합.
- **연합뉴스 API**: 공개된 셀프서비스 상업 이용약관 페이지를 찾지 못했음 — 통상 기업 대상 유료 콘텐츠 제휴/DB 계약(뉴스와이어류 제휴사 모델과 유사)으로 운영되는 것으로 보이며, 문서화된 "무료 상업적 재이용 허용" 근거는 확인되지 않음. 개별 협의 필요.
- **네이버 뉴스 검색 API**: `developers.naver.com`은 이 세션에서 접근이 차단되어 정확한 조항 원문을 직접 확인하지 못했다(중요 — 빌드 전 반드시 재확인 필요). 일반적으로 알려진 바로는 제목·요약(스니펫)·링크만 반환하며 기사 본문 전재는 제공하지 않는다. 다만 이것이 "광고 수익이 있는 상업 서비스에서 자유롭게 재게시 가능"을 보장하는 것은 아니며, Open API 이용약관상 호출량 제한·서비스별 승인 절차가 있을 수 있으므로 확인 없이 전제하면 안 된다.

**종합**: 한국 언론사 뉴스는 "헤드라인+링크만" 이어도 업계 자율규칙(KPF/한국디지털뉴스협회)상 상업적 재게시는 원칙적으로 언론사·재단과의 계약이 필요하다고 명시되어 있다. 정부/공공 뉴스 아그리게이터(빅카인즈) 역시 상업적 자유 재이용을 허용하지 않는다. "무계약으로 안전하게 쓸 수 있는" 한국 언론사는 이번 조사에서 확인되지 않았다.

## 결론 요약

**지금 바로 만들어도 되는 것: 없음.** 조사한 국내 공공기관·언론사 어느 곳도 "공공누리 제1유형(완전 자유, 상업적 이용 가능)" 또는 명시적 상업 재게시 허가를 제공하지 않았다.

**법적으로 위험하거나 유료 계약이 필요한 것:**
- 신기술 섹션 국내판(NTIS/KIAT/STEPI) — 구조적으로(뉴스형 RSS 부재) + 라이선스상(상업 이용 사전협의/금지) 이중으로 막혀 있음. 지금 방식(무단 자동 스크레이핑 후 AI 재요약)으로 진행하면 NTIS·STEPI 양쪽 모두 저작권/공공데이터법 위반 소지.
- 한국 언론사 뉴스 전반 — KPF/한국디지털뉴스협회 규칙상 상업적 재게시는 개별 언론사 또는 재단과의 유료 계약이 원칙. 빅카인즈도 동일.
- Yahoo Finance 비공식 API — 기존에도 "unofficial, may break"로 이미 플래그되어 있지만, 이번 조사로 "약관상 허가된 접근이 아니다"라는 점이 추가로 확인됨. 이미 운영 중인 리스크이므로 즉시 중단할지는 사업 판단이지만, 국내 뉴스를 같은 방식(비공식 접근)으로 확장하는 것은 권장하지 않음.
- 국내 산업전망(KIET/KDI/BOK/대한상의/KITA) — 전부 상업적 재이용 금지 또는 조건부. 특히 KITA는 크롤링 자체를 금지하는 조항이 있어 자동 수집 스크립트로 접근하는 것 자체가 약관 위반.

**현실적으로 취할 수 있는 다음 단계 (건축 전 검토 권장, 코드 작성 없이 리서치로만 정리):**
1. 국내 신기술/산업전망 섹션은 "정부기관 콘텐츠 재게시"가 아니라, 팀이 직접 공개 통계(예: 공공데이터포털의 제공대상 공공데이터로 지정된 것들, 이는 공공데이터법상 자유이용)만 골라 자체 문장으로 재구성하는 방향으로 좁혀야 한다.
2. 한국 뉴스 섹션은 네이버 뉴스 검색 API의 정확한 상업적 이용 조항(개발자센터 접속 후 원문 확인, 이번 세션에서는 접근 차단으로 미확인)을 먼저 확인하고, 그 결과에 따라 헤드라인+링크 표시 범위를 결정할 것을 권장. 확인 전에는 삼성전자/SK하이닉스 뉴스도 구현하지 않는 것이 안전하다.
3. 유료 계약이 필요한 경로(연합뉴스 API, KPF 뉴스저작권 계약, KIET/KDI 등 상업 라이선스)는 트래픽·매출 규모가 계약 비용을 정당화할 때 별도로 재검토.
